# MLOps · ДЗ 3: вопросы по статьям об NLP

Пайплайн строит chat-датасет из [QASPER v0.3](https://allenai.org/data/qasper): оставляет вопросы с проверяемым извлекаемым ответом, очищает их, проверяет разнообразие и делит по статьям. Исходные JSON и итоговые JSONL версионируются DVC; в git находятся только код, метрики и указатели. Тему датасета необходимо согласовать с преподавателем.

```bash
uv sync
make source        # скачать официальный источник и проверить SHA-256; нужен один раз
make v1            # QASPER train → 1215 примеров после очистки
make v2            # train + dev → 1777 примеров после очистки
make check         # все восемь блоков самопроверки
make diff          # сравнение метрик после фиксации версий
```

После восстановления данных из локального DVC remote вместо `make source` можно выполнить `uv run dvc pull`. Для сохранения текущей версии данных в remote: `uv run dvc push`. Граф: `make dag`; отдельные гейты: `make diversity`, `make contamination`.

Команды `make v1` и `make v2` переключают версию и обновляют `dvc.lock` и метрики. После того как обе версии зафиксированы в вашей истории, `uv run dvc metrics diff <ревизия-v1> <ревизия-v2>` покажет их разницу. `make diff` запускает стандартное сравнение рабочей версии с последней зафиксированной. Подробности состава и ограничений — в [паспорте](docs/datasheet.md), пять исправленных дефектов — в [разборе](docs/defects.md).
